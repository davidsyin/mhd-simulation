# Scripts Directory

## Overview

This directory contains utility scripts for various tasks related to model evaluation, visualization, and data processing. These scripts are provided as-is for convenience and quick prototyping.

## Important Notice

⚠️ **Please read carefully before using these scripts**

- **Development approach**: Scripts in this directory were developed quickly for specific use cases and are **not fully integrated** with the main repository architecture
- **AI-assisted development**: Most scripts were generated with LLM/Agent/RAG assistance for rapid prototyping
- **Limited testing**: While the scripts appear to work for their intended purposes, they have not undergone comprehensive testing
- **No maintenance**: These scripts come with **absolutely zero guarantee** and will not receive ongoing maintenance or updates
- **No pull request support**: Pull requests related to scripts in this directory will **not be reviewed or merged**

## Usage

Scripts are provided for:
- Model evaluation and analysis
- Publication-quality visualization generation
- Data processing and statistics calculation
- Video generation for temporal evolution

Each script includes basic usage instructions in its docstring. Use at your own discretion and validate outputs carefully.

## Recommendations

For production use or integration into research workflows, consider:
- Thoroughly testing scripts with your specific data and use cases
- Adapting and refactoring code to meet your quality standards
- Implementing proper error handling and validation
- Creating your own maintained versions based on these examples

## Support

For issues with these scripts, users are encouraged to:
- Debug and fix issues independently
- Create their own improved versions
- Use the scripts as starting points rather than final solutions

The main repository maintainers focus on the core framework and will not provide support for these utility scripts.
